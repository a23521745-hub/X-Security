## Reporting a Vulnerability

Security is a top priority for this project. If you discover a potential vulnerability, security issue, or unexpected flaw in the application or scanner engine, please report it responsibly instead of opening a public issue.

### How to Report

1. **Private Email:** Send details to your contact email or open a private GitHub Advisory disclosure.
2. **Details to Include:**
   - Type of issue (e.g., buffer overflow in JNI layer, bypass in YARA matching engine, permission escalation).
   - Steps to reproduce the vulnerability.
   - Proof of Concept (PoC) code or sample APK (if applicable).
   - Affected Android versions or device architectures.

### Disclosure Process

- **Acknowledgment:** You will receive an initial response acknowledging your report within **48 hours**.
- **Assessment:** The report will be analyzed, and a fix will be prepared in a isolated environment.
- **Resolution:** A security patch will be pushed to the repository, and credit will be given in the release notes unless you wish to remain anonymous.
